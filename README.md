# Media Grabber releases

Installers and update files for Media Grabber, a small desktop app that saves public YouTube and
Facebook videos as MP3 or MP4 and trims clips.

**[Download the latest version](https://github.com/4realIA/media-grabber-releases/releases/latest)**

- **Windows:** the file ending in `windows_x64-setup.exe`
- **Mac (Apple Silicon):** the file ending in `macos_arm64.dmg`

The app updates itself after it's installed. Every update is signed, and the app checks the
signature before installing anything.

The source code is kept separately. These builds bundle FFmpeg (GPL), Deno (MIT), and download
yt-dlp (Unlicense) on first run.
